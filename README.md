"# Ghosts'N'Goblins" 
port of Ghosts'n'Goblins for Amiga AGA

Requires a 2-button joystick, or the keyboard, some fast memory or CD32 :)

Features:

- all 7 levels in 64 colors
- PAL/NTSC (NTSC seems better for scrolling)
- exact arcade gameplay
- awesome music
- difficulty/lives settings
- service mode :)

Instructions:

5 or fire: insert coin
1/2 or joy up/down:  start game
arrows/joystick: move
red/ctrl: shoot
blue/alt: jump
continue: fire
ESC: quit current game

Cheat keys:

F1: toggle invincibility
F2: level skip
F3: switch weapon (not visible in the HUD at once)
F4: warp higher (useful in tower levels)
F5: add to score
