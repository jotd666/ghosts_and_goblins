"# Ghosts'N'Goblins" 
port of Ghosts'n'Goblins for Amiga

Requires a 2-button joystick, or the keyboard

  sound conversion for the Amiga.

Instructions:

5: insert coin
1/2: start game
arrows/joystick: move
red/ctrl: shoot
blue/alt: jump
continue: 1P start+fire

Cheat keys:

F1: toggle invincibility
F2: level skip
F3: switch weapon (not visible in the HUD at once)
F4: warp higher (useful in tower levels)
F5: add to score
